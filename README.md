Proyecto desarrollado en Java como parte de la práctica de Programación Orientada a Objetos.

## Descripción

Este proyecto implementa una solución utilizando conceptos fundamentales de Java, como clases, objetos, herencia, interfaces, métodos y estructuras de control.

## Tecnologías utilizadas

- Java
- IntelliJ IDEA
- Git
- GitHub

## Características principales

- Uso de clases y objetos.
- Aplicación de principios de Programación Orientada a Objetos.
- Organización del código por paquetes.
- Ejecución desde una clase principal con método `main`.

## Estructura general

El proyecto está organizado en paquetes, separando las clases principales, interfaces y la clase encargada de ejecutar el programa.

## Cómo ejecutar el proyecto

1. Clonar el repositorio.
2. Abrir el proyecto en IntelliJ IDEA o cualquier IDE compatible con Java.
3. Ejecutar la clase que contiene el método `main`.
